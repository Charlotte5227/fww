# 筒ビューア

画像を筒（円柱）に巻き付けて、回しながら見られるサイトです。GitHub Pages でそのまま公開できます。

- **閲覧ページ**（`/`）… 筒を回して見る、筒⇔平面の切り替え、上部のチェックでレイヤーの表示／非表示
- **管理ページ**（`/admin/`）… 下地画像・レイヤー・背景画像の設定、表示設定、GitHub への公開
- **お絵かきページ**（`/draw/`）… 最新の地図の上に、自分のブラウザの中だけで線や図形を描ける

ビルド作業は不要です。このフォルダの中身をそのままリポジトリに置けば動きます。

---

## 公開までの手順

### 1. リポジトリを作ってファイルを置く

1. GitHub で新しいリポジトリを作ります（例：`cylinder-viewer`、Public）。
2. このフォルダの中身（`index.html`、`admin`、`assets`、`data`、`.nojekyll` など）をすべてリポジトリの直下にアップロードします。
   - ブラウザから行う場合は、リポジトリの「Add file」→「Upload files」にフォルダごとドラッグします。
   - `.nojekyll` は隠しファイルなので、アップロードから漏れていないか確認してください（なくても動きますが、あると反映が速くなります）。

### 2. GitHub Pages を有効にする

1. リポジトリの「Settings」→「Pages」を開きます。
2. 「Source」を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
3. 1〜2分後、`https://ユーザー名.github.io/リポジトリ名/` で閲覧ページが開けます。
   管理ページは `https://ユーザー名.github.io/リポジトリ名/admin/` です。

### 3. 管理ページから更新できるようにする（アクセストークン）

管理ページの「公開する」ボタンは、GitHub のリポジトリに直接ファイルを保存します。そのためにトークンが必要です。

1. GitHub の [Fine-grained token の作成ページ](https://github.com/settings/personal-access-tokens/new) を開きます。
2. 「Repository access」→「Only select repositories」で、このリポジトリだけを選びます。
3. 「Permissions」→「Repository permissions」→「Contents」を **Read and write** にします。
4. 作成されたトークン（`github_pat_` で始まる文字列）をコピーします。
5. 管理ページの「公開先（GitHub）」に、ユーザー名・リポジトリ名・トークンを入れて「接続する」を押します。
   GitHub Pages 上で開いた場合、ユーザー名とリポジトリ名は自動で入ります。

> 管理ページ自体は誰でも開けますが、トークンがなければ何も変更できません。
> トークンはそのブラウザの中にだけ保存されます。共用のパソコンでは「このブラウザにトークンを保存する」のチェックを外してください。

## 使い方

### 管理ページ

| やりたいこと | 操作 |
| --- | --- |
| 下地画像を設定 | 「下地画像」の「画像を選ぶ」、またはドロップ |
| レイヤーを追加 | 「画像を選んで追加」（複数可）、ドロップ、`Ctrl`+`V`／`⌘`+`V` で貼り付け |
| 重なり順を変える | レイヤーの ↑（手前へ）／↓（奥へ）。リストの上ほど手前 |
| 最初から表示するか | レイヤーの「最初から表示」 |
| 筒の後ろの背景 | 「筒の背景」で画像・背景色・配置を設定 |
| 反映する | 画面下の「公開する」。1〜2分で閲覧ページに反映 |

- 画面左（スマホでは上）のプレビューで、公開前に見た目を確認できます。
- 下地が未設定のときに貼り付けた画像は、自動で下地になります。
- 8192px を超える大きな画像は、スマホでも表示できるよう自動で縮小されます。
- レイヤーは**下地と同じ縦横比**の画像（透過PNG）にすると位置がぴったり重なります。違う比率の画像は下地の大きさに合わせて伸縮されます。

### 履歴（過去の地図）

- 管理ページから公開すると、そのときの地図が「履歴」に記録として残ります。1日に何回でも記録できます。
- 公開する前に、「履歴」欄で記録の内容を決められます。
  - **記録の日付・時刻**：変更しなければ公開した日時になります。ゲーム内の日付など、好きな日付を入れてもかまいません。
  - **新しい記録として追加**（通常）／**直前に公開した記録を上書き**（誤字の修正など、小さな修正のとき）
  - **メモ**：「第12ターン」など。閲覧ページや Discord の日付一覧に表示されます。
- 記録の一覧では、記録ごとに日付・時刻・メモの変更、プレビュー、「編集に読み込む」（その記録の地図を元に編集し直す）、削除ができます。変更は「公開する」で保存されます。
- 履歴が使っている画像は削除されずに残ります。記録を削除して公開すると、その記録だけが使っていた画像も削除されます。
- 「これまでの公開から履歴を作る」で、GitHub に残っている過去の公開を履歴に取り込めます（画像のアップロードはやり直しません。同じ内容の記録は追加されません）。
- 履歴は `data/history.json` に保存されます。

### 閲覧ページ

- 横にドラッグ（スワイプ）で筒が回ります。勢いをつけると惰性で回ります。
- ピンチ／ホイールで拡大、拡大中は縦ドラッグで上下に移動、ダブルタップで元の大きさに戻ります。
- 下のダイヤルでも回せます（キーボードの ← → も使えます）。
- 上部の「透明度」ボタンで、レイヤーごとの透明度をスライダーで変えられます（その場の表示だけが変わり、管理ページの設定は変わりません。「透明度を元に戻す」で管理ページの設定値に戻ります）。
- 右上のボタンで「筒」と「平面」を切り替えます。
- 平面表示でも左右にドラッグすると、画像の枠の中で左右がつながったまま流れます（筒と同じ向きを共有しているので、切り替えても見ている位置はそのままです）。
- 右上の目のボタン（または `H` キー）で、地図以外の表示をすべて隠します。もう一度押すと戻ります。
- 右下の保存ボタンで、画像の保存メニューが開きます。スマホでは共有メニューが開き、「画像を保存」で写真に保存できます。
  - **レイヤー画像を保存**：各レイヤーの元画像を、レイヤー名のファイル名（例：`国家.png`）で保存。「すべてまとめて保存」で ZIP にもできます。
  - **地図全体を保存**（平面表示のとき）：今のレイヤーの表示・透明度のまま、地図全体を元の解像度で保存（左右の位置は元の画像のまま）。
  - **表示範囲を保存**（平面表示のとき）：拡大して画面に映っている範囲だけを保存。

- レイヤー欄の先頭の日付ボタン（「最新」）で、過去の日付の地図に切り替えられます。レイヤーの表示や拡大はそのままなので、日付を切り替えて見比べられます。過去の記録を表示しているときは、ボタンにその日時が表示されます。そのときのページの URL（`?v=…`）を共有すると同じ記録の地図が開きます。`?date=2026-10-26` のように日付で開くと、その日のいちばん新しい記録になります。

### お絵かきページ

閲覧ページ右上の鉛筆ボタン（または `/draw/`）で開きます。誰でも使えますが、描いた内容は**そのブラウザの中だけ**に保存され、公開中の地図やほかの人には一切影響しません。地図は常に最新のものが使われます。

- 描くのは平面表示です（左右はつながっていて、端をまたいだ線・図形・塗りつぶしは反対側に続きます）。「筒」は見た目の確認用で、筒の上には描けません。
- 移動・拡大：スマホは2本指、パソコンはホイール（`Space` を押しながらドラッグでも移動）。「移動」ツールなら1本指でも動かせます。
- ツール：ペン、消しゴム（選んでいるレイヤーだけ消す）、定規（直線・折れ線、角度を15°ずつそろえる、長さを表示）、図形（四角・丸・三角・矢印、枠線／塗り／両方、確定前は角のつまみで調整・ほかの場所をタップで確定）、塗りつぶし（「見えている地図」の境界か「このレイヤー」だけを見るか選べる）、スポイト、色。
- 元に戻す／やり直す（50回まで）：描いた操作に加えて、レイヤーの追加・削除・並べ替え・名前・透明度の変更も戻せます（表示／非表示は記録しません）。
- レイヤー（下のバーのボタン）：地図のレイヤーは並べ替え・表示・透明度だけ変えられます。お絵かきレイヤーは10枚まで追加・複製・名前の変更・削除ができ、地図のレイヤーの間にも置けます。✏️ が付いたレイヤーに描きます。
- 保存：レイヤー画像・地図全体・表示範囲を、閲覧ページと同じようにPNGで保存できます（今の表示・透明度・重なり順のまま）。
- 作業のバックアップ：描いた内容は自動でブラウザに保存されます。ブラウザのデータを消すと失われるので、「作業を保存（ZIP）」でファイルにも残しておくと安心です（最後のバックアップから7日たつとお知らせが出ます）。「作業を再開（ZIP）」で、そのファイルから続きを描けます。
- 定規の長さを km で表示したいときは、管理ページの「表示」にある「地図の横幅（一周の長さ）」を設定してください。

キーボード：`V` 移動、`P` ペン、`E` 消しゴム、`L` 定規、`S` 図形、`G` 塗りつぶし、`I` スポイト、`[` `]` 太さ、`Ctrl`+`Z` 元に戻す、`Ctrl`+`Y` やり直す、`Enter` 確定、`Esc` 取り消し、`0` 全体を表示、`H` 表示を隠す。

Discord の `/地図` コマンドで地図を投稿する機能もあります。設定方法は [discord/README.md](discord/README.md) を見てください。

## GitHub を使わずに更新する場合

管理ページ下部の「ZIP をダウンロード」で、設定と画像をまとめた ZIP を保存できます。
展開してできた `data` フォルダで、リポジトリの `data` フォルダを置き換えてください。

## 手元のパソコンで確認する場合

`file://` で直接開くと読み込みが制限されるため、簡易サーバーを使います。

```sh
cd このフォルダ
python3 -m http.server 8000
# → http://localhost:8000/ と http://localhost:8000/admin/（お絵かきは /draw/）を開く
```

## ファイル構成

```
index.html              閲覧ページ
admin/index.html        管理ページ
draw/index.html         お絵かきページ
assets/js/engine.js     筒の描画・平面表示・操作（両ページ共通）
assets/js/viewer.js     閲覧ページの動作
assets/js/save.js       閲覧ページの画像保存メニュー
assets/js/history.js    閲覧ページの日付の切り替え
assets/js/dial.js       回転ダイヤル
assets/js/admin.js      管理ページの動作
assets/js/draw/         お絵かきページの動作（main.js が入口）
assets/js/github.js     GitHub への保存（1回の公開＝1コミット）
assets/css/             スタイル
assets/vendor/          three.js（必要な部分だけ）、JSZip
data/config.json        表示内容の設定（管理ページが書き換えます）
data/history.json       日付ごとの履歴（管理ページが書き換えます）
data/images/            画像（管理ページがアップロードします）
discord/                Discord 連携（Cloudflare Worker と設定手順）
tools/                  Discord 連携で GitHub Actions が使うスクリプト
.github/workflows/      Discord 連携用の GitHub Actions
```

`data/config.json` の主な項目：

```jsonc
{
  "title": "表示タイトル",
  "base": { "name": "下地", "src": "data/images/xxx.jpg" },
  "layers": [ { "id": "...", "name": "雲", "src": "data/images/yyy.png", "visible": true, "opacity": 1 } ],
  "background": { "src": "data/images/zzz.jpg", "color": "#141a2e", "fit": "cover" },
  "display": { "defaultMode": "cylinder", "autoRotate": true, "rotateSpeed": 6, "shading": 0.55, "startAngle": 180, "widthKm": 40000 }
}
```

- `layers` は配列の後ろほど手前に描かれます。
- `widthKm`（省略可）は地図の横幅（一周）の長さです。お絵かきページの定規の km 表示に使います。
- `startAngle` は開いたときに正面（平面表示では枠の中央）に来る位置です（0＝画像の左端、180＝中央＝元の画像のまま）。

## プログラムを書き換えたとき（キャッシュ対策）

GitHub Pages ではブラウザが CSS・JavaScript をしばらく再利用するため、更新直後は古い動きのままになることがあります。
読み込み先に `?v=20261028-1` のようなバージョン番号を付けているので、プログラムを書き換えたら次のファイルの番号をすべて同じ新しい値に変えてください（管理ページからの画像や設定の更新では不要です）。

- `index.html`、`admin/index.html`、`draw/index.html`（CSS と JS の読み込み）
- `assets/js/viewer.js`、`assets/js/dial.js`、`assets/js/admin.js`、`assets/js/draw/` の各ファイル（`import` の行）

すぐに確かめたいときは、強制再読み込み（Windows：`Ctrl`+`F5`、Mac：`⌘`+`Shift`+`R`）でも最新になります。
