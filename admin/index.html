公開先（GitHub）

ここで接続すると、「公開する」ボタンで GitHub のリポジトリに直接保存され、GitHub Pages の閲覧ページに反映されます。

トークンの作り方
  1. GitHub の Fine-grained token の作成ページを開きます。
  2. 「Repository access」で「Only select repositories」を選び、このサイトのリポジトリだけを選びます。
  3. 「Permissions」の「Contents」を「Read and write」にします。
  4. 作成したトークン（github_pat_ で始まる文字列）をここに貼り付けます。

トークンはこのブラウザの中だけに保存され、GitHub 以外には送信されません。共用のパソコンでは「保存する」のチェックを外してください。
